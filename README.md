# No Steps, Only Leaps!

**No Steps, Only Leaps!** is a small 2D precision platformer made with Unity and C#.

This is my first complete game project. I built it as a portfolio project while learning Unity, 2D game development, gameplay programming, UI systems, saving, and WebGL publishing.

[🎮 **Play the demo**](https://emresner.github.io/no-steps-only-leaps/)

---

## 🎯 About the Game

The player cannot walk.

Instead, movement is based on charging and releasing jumps. The goal is simple: make your way to the top and finish the game as fast as you can.

Platforms, traps, checkpoints, and other obstacles are there to get in your way, slow you down, and make every jump count. A bad jump might only cost a few seconds, or send you falling far enough to lose a lot more time.

The game is inspired by precision platformers where getting a better run means learning the level and getting more consistent with every attempt.

---

## ✨ Features

* Charge-based jump movement
* No-walk precision platforming
* Direction-based jumping
* Wall bounce behavior
* Hard landing / hit state
* Checkpoint system
* Trap systems

  * spikes
  * fire traps
  * moving spiked balls
  * falling platforms
* Collectibles with persistent fruit balance
* Unlockable and selectable skins
* Best time saving
* Main menu, market, pause menu, and ending UI
* Typewriter-style ending dialogue
* Audio toggle
* WebGL browser demo

## 🧩 Repository Notes

This repository is mainly a **source code showcase**.

The playable WebGL demo is deployed from the `gh-pages` branch.

Third-party art, audio files, Unity scenes, prefabs, and full project assets are not included in the source branch.

## 🧠 Development Notes

This project started as a learning-focused 2D platformer and slowly turned into a complete small game.

Some of the systems I worked on include:

* Player state machine
* Charge jump tuning
* Camera behavior
* Checkpoint and respawn flow
* Trap knockback
* Collectible saving
* Skin unlock/select system
* Main menu and market UI

I also created some small UI assets myself in Aseprite, including custom buttons and icons, to make the project feel more personal.
